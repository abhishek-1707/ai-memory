Revisions, Provenance & Verification

Every memory write creates an immutable revision with author and device provenance. Optimistic concurrency checks prevent stale overwrites, while verification flags mark confirmed truths.

Workflow

How OmniMemory Works

A disciplined, local-first coordination cycle between you and your AI agents.

1

Store Project Knowledge

Store project architecture, guidelines, schema decisions, and critical context in your local SQLite store.

2

Equip Authorized Agents

Authorized agents connect via local stdio MCP or authenticated REST to query relevant context before taking action.

3

Track Tasks & Progress

Agents advance tasks through validated status transitions, recording evidence and verified results at each milestone.

4

Record Clean Handoffs

Create immutable handoff records that summarize completed work and blockers so another agent or session resumes without context loss.

Integration Boundary Notice: OmniMemory provides open, standardized interfaces (MCP over stdio and loopback REST). Third-party AI tools do not integrate automatically without being explicitly configured with authorization.
Trust & Architecture

Privacy & Security Protections

Designed from first principles to keep your project knowledge under your control.

Implemented Protections

  • Local-First Storage: Your data is stored exclusively on your local computer in a SQLite database file with WAL mode.
  • Loopback Isolation: The REST API binds strictly to 127.0.0.1. Foreign origins and remote requests are rejected.
  • Cryptographic Credentials: Master passwords use asynchronous scrypt with random salts; tokens are hashed with SHA-256.
  • Audit Logging & Permissions: Security state changes and device enrollments are recorded in an append-only audit log.

Accurate Privacy Boundaries

We believe in complete transparency about what is implemented today versus what is deferred.

What Local-First Means Here:

Local-first means your data resides on your machine and works without an internet connection. It does not mean OmniMemory automatically synchronizes across multiple computers or phones.

We do not claim end-to-end cloud encryption, remote internet relay, or automated cloud backups because those features have not yet been built or tested.

Help & Answers

Frequently Asked Questions

Clear answers reflecting the real, unvarnished state of OmniMemory.

What is OmniMemory?

OmniMemory is a local-first memory and coordination engine for AI agents and developers. It provides project-scoped memory with lexical search, task tracking with validated state transitions, and immutable handoff records so AI agents can share durable context across sessions without relying on third-party cloud memory databases.

Does it require Node.js to be installed separately?

No for the Windows desktop application: The desktop app embeds Electron 45 with its own bundled Node 24 runtime and native SQLite engine. You do not need to install Node.js separately to run the desktop app.

Yes for development and CLI MCP server: If you run OmniMemory from source or execute the standalone MCP stdio script in development, Node.js 24 or newer is required to support the native node:sqlite module.

Where is my memory stored?

Your memory is stored locally in an authoritative SQLite database on your computer. In the Windows desktop application, the database is placed in your per-user application data directory:

%APPDATA%\OmniMemory\omnimemory.sqlite

The database is never placed in the installation folder, and uninstallation does not delete your memory data.

Does it connect every AI application automatically?

No. AI applications do not connect automatically. OmniMemory exposes standard Model Context Protocol (MCP) over local stdio and an authenticated loopback REST API. Compatible AI tools (such as Claude Desktop, Cline, or custom agent scripts) must be explicitly configured with an authorized session token and target project ID.

Can I use it on my phone?

Not in the current release. The backend binds strictly to loopback (127.0.0.1) on your PC and rejects connections from non-loopback network interfaces. Secure same-Wi-Fi device access is planned for a future release once certificate pinning and LAN authentication are implemented.

Can I connect from anywhere?

No. There is currently no cloud sync, remote relay, or public internet listener. OmniMemory operates entirely on your local machine. Remote connectivity is on our future roadmap.

Is the Windows installer ready?

The packaging pipeline and executable smoke tests are complete in development, producing the 110.8 MB NSIS installer (OmniMemory-0.1.0-x64-Setup.exe). However, physical Windows installation and launch verification are in progress before official public release binaries are published to mirrors. You can currently build and test the package locally from source.
